# Security policy

Please do not disclose invoice-validation vulnerabilities in a public issue.
Use GitHub's private vulnerability reporting for this repository and include a
minimal synthetic invoice, the affected release, expected and observed rule
IDs, and whether the discrepancy could cause a false acceptance.

Only the latest release line will receive security fixes before version 1.0.
No release is approved for fiscal issuance unless its attached conformance
report says so explicitly.
