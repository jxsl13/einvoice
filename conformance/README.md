# Conformance evidence

This directory contains deterministic evidence generated from checksum-pinned
upstream artifacts. It does not, by itself, assert fiscal conformance.

`xrechnung-3.0.2-rules.json` inventories every predicate activated by phase
`xrechnung-model` in the pinned XRechnung Schematron 2.5.0 sources. Each entry
binds the syntax, pattern, severity, normalized context, normalized test, and a
SHA-256 digest. The inventory separates standard, PEPPOL, extension, and CVD
groups so partial profile support cannot be represented as full support.

Regenerate the file from the exact archive in
`.github/dependencies/parity.json`:

```console
go run ./cmd/genruleinventory -archive /path/to/xrechnung-3.0.2-schematron-2.5.0.zip
```

CI downloads that archive over HTTPS, verifies its pinned SHA-256, and compares
the regenerated bytes with the checked-in inventory. The generator extracts
only three bounded regular Schematron members and resolves only local includes.
It rejects digest drift, missing or duplicate IDs, unresolved or repeated
patterns, include cycles, path escapes, remote includes, empty predicates, and
unknown severities.

All capability flags remain false until executable mappings, per-predicate
witnesses, mutation testing, and differential KoSIT parity meet every gate in
`CONFORMANCE.md`. Extension and CVD remain outside the initial release scope.
